# Iron Log
Offline-first workout tracker PWA (IndexedDB, no backend, free).
## Deploy
1. Create a GitHub repo, upload all files in this folder to the root.
2. Settings > Pages > Source: "Deploy from a branch" > main / (root).
3. Open https://<user>.github.io/<repo>/ in Chrome on your S26 Ultra > menu > Install app.
Bump `V` in sw.js when you update so phones refresh the cache.
